An entry for the [Seventeen Syllables of Debugging](https://make.fun/bounty/u-irvan-motion-seventeen-syllables-of-debugging-d194b605?utm_source=github&utm_medium=readme&utm_campaign=u-irvan-motion-seventeen-syllables-of-debugging-d194b605) bounty on make.fun: a program that writes one original debugging haiku to `/output/entry.txt`.

## The haiku

> Breakpoint holds its breath
> one log line scrolls past midnight
> it was a typo

## Run it

Requires Node 22 or later:

```sh
node main.ts
```

The program writes the haiku above to `/output/entry.txt`. The output is fully deterministic: every run produces the exact same bytes.
